# Police Tragedy

Публичный архив историй офицеров и записей бодикамер.

Сайт: после публикации GitHub Pages откроется по адресу  
`https://<твой-логин>.github.io/police-tragedy/`

## Как пользоваться

- Искать офицера по имени, жетону или позывному
- Открыть карточку: история персонажа и последняя запись бодикамеры

Чтобы добавить новое дело локально:

1. Установи [Node.js](https://nodejs.org)
2. В папке проекта запусти `start.bat`
3. Зайди в админку: http://localhost:3000/admin (пароль по умолчанию `tragedy`)
4. Залей историю, mp4 и демку
5. Сделай `git add` / `git commit` / `git push` — GitHub Pages обновит публичный сайт
